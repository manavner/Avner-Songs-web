# חיבור כפתור UPDATE לגיליון

כפתור **🔄 UPDATE** באתר קורא לסקריפט Google Apps Script שיושב בתוך הגיליון "Avner Man Songs".
הסקריפט מחפש ב-YouTube שירים של אבנר מן שעדיין לא בגיליון, ומוסיף אותם לסוף הרשימה. הוא בודק:

- הערוץ "אבנר מן" (`UC0b65NhvnAnsmIJaBnj1J1g`), לשירים שהעלית בעצמך
- הערוץ "Avner Man - Topic" (`UCz1luN4ETMqoUnBW6ojE42Q`), לשירים שעלו דרך DistroKid
- חיפוש ב-YouTube של "Avner Man" ו-"אבנר מן". מתוצאות החיפוש נוספים רק סרטונים מערוצים ששמם מכיל את השם הזה.

נוספים רק סרטונים ציבוריים. סרטונים פרטיים או לא-רשומים לא נוספים.

## התקנה (פעם אחת, כ-5 דקות)

1. פתח את הגיליון ← **הרחבות (Extensions) ← Apps Script**.
2. מחק את התוכן של `Code.gs` בעורך, והדבק במקומו את התוכן של [Code.gs](Code.gs) מהתיקייה הזו.
3. משמאל, ליד **שירותים (Services)**, לחץ **+**, בחר **YouTube Data API v3** ולחץ **הוסף (Add)**.
4. שמור (Ctrl+S). בסרגל העליון בחר את הפונקציה `updateSongs` ולחץ **הפעלה (Run)**.
   Google תבקש אישור הרשאות: גישה לגיליון ול-YouTube. אשר אותה עם החשבון שלך.
   בהרצה הזו השירים החדשים כבר יתווספו לגיליון.
5. **פריסה (Deploy) ← פריסה חדשה (New deployment)** ← סוג: **אפליקציית אינטרנט (Web app)**:
   - Execute as: **Me**
   - Who has access: **Anyone**
6. לחץ **Deploy** והעתק את ה-**Web app URL** (מסתיים ב-`/exec`).
7. ב-`index.html` הדבק את הכתובת בשורה:
   ```js
   const UPDATE_SCRIPT_URL = 'https://script.google.com/macros/s/.../exec';
   ```

## הערות

- אם לא מוסיפים את שירות YouTube (שלב 3), הסקריפט עובר ל-RSS. במצב הזה הוא רואה רק את 15 הסרטונים האחרונים בכל ערוץ.
- הכתובת ציבורית, כך שכל מי שלוחץ UPDATE באתר מפעיל את החיפוש. זה בטוח: הסקריפט רק מוסיף סרטונים מהערוצים שלך, ולא מוסיף שיר פעמיים.
- אם תשנה את `Code.gs` בעתיד: **Deploy ← Manage deployments ← ✏️ ← Version: New version**. כך הכתובת נשארת אותה כתובת.
